**KLXM Studio** ist ein Multi-Site-CMS ohne Framework für PHP 8.4+, entwickelt von der KLXM Crossmedia GmbH in Moers.
Statt Themes gibt es **Kits**: Ein Kit ist das ganze Fundament eines Projekts – Design, Blöcke, Datenstrukturen,
Einstellungen und Startinhalte.

> **Status:** in Entwicklung (Vorschau). Es gibt noch kein offizielles Release.

- **Blöcke & Bearbeiten auf der Website** – Blockeditor mit Entwurf, Veröffentlichen und Versionen
- **Mediathek** mit zerstörungsfreier Bildbearbeitung, Zuschnitten und Untertiteln
- **Datentabellen & Formulare** ohne Code – mit Detailseiten, Kalender und verschlüsselten Eingängen
- **Multi-Site & Netzwerk** – viele Websites aus einer Installation, zentral verwaltet
- **Barrierearm und datenschutzfreundlich** – Ziel WCAG 2.2 AA, cookiefrei ab Werk
- **KLXM Ai** – auf Wunsch lokal (Ollama) oder über EU-Anbieter; Erweiterungen als Composer-Pakete

### English

**KLXM Studio** is a framework-free multi-site CMS for PHP 8.4+, built by KLXM Crossmedia GmbH in Moers, Germany.
Instead of themes it uses **kits**: a kit is a complete project foundation – design, blocks, data structures,
settings and starter content.

> **Status:** in development (preview). There is no official release yet.

- **Blocks & on-page editing** – block editor with drafts, publishing and revisions
- **Media library** with non-destructive image editing, crops and captions
- **Data tables & forms** without code – with detail pages, calendar and encrypted inboxes
- **Multi-site & network** – many websites from one installation, managed centrally
- **Accessible and privacy-friendly** – targeting WCAG 2.2 AA, cookie-free by default
- **KLXM Ai** – optionally local (Ollama) or via EU providers; extensions as Composer packages
